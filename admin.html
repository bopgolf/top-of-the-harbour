Sign in

Changes you make here are saved to the leaderboard's GitHub project. To sign in you need a GitHub access key for this project. You only make the key once.

How to make your access key (about 2 minutes)
  1. Sign in to GitHub, then open github.com/settings/personal-access-tokens/new.
  2. Token name: Leaderboard organiser. Expiration: choose the longest available (e.g. 366 days). You'll make a new one when it expires.
  3. Repository access: choose Only select repositories and pick top-of-the-harbour.
  4. Permissions → Repository permissions: set Contents to Read and write and Actions to Read and write.
  5. Click Generate token and copy it (it starts with github_pat_). Paste it below.

Events & results links

Status: On counts as normal · Off hides the event from the leaderboard (e.g. not confirmed yet) · Cancelled shows it as cancelled. Use the arrows to reorder; rounds are numbered top to bottom when you save, and any fixes move with their event. Short name is the word shown under each round on the leaderboard (e.g. Taupō); leave it blank to use the venue. Paste each event's results link(s) in the Results links box, one per line. Golf NZ links are read automatically; add both the 18-hole and 9-hole links. A link to a Google Sheet published as CSV, or a file uploaded on the Upload results tab, also works.

Add a fix

Fixes always win over the results feeds, and stay in place when new results come in. Names are matched as Last, First; capitals and accents don't matter.

Upload results for an event

For an event that wasn't scored on Golf NZ. Copy the results from Excel (four columns: player, club, holes, points) and paste them below, or choose a CSV file. Enter raw stableford points; 9-hole cards get 17 added automatically.

Clubs

Logos: click Upload next to a club and choose its logo (PNG or JPG, ideally square). It's resized and saved straight away. Players count for the club shown on their results. If a results system spells a club differently, add that spelling under Other spellings (separate several with ;). Clubs set to No are listed below the standings without a position.

Starting a new season: change the season here and set Status to Live; update the events and their links; then remove last season's fixes on the Fixes tab.

Your logo and header

Your logo appears at the top left of the leaderboard, beside the title. A logo with a transparent background works best. Colours are on the Season settings tab.

Sponsors

Sponsors appear in a Supported by strip under the header, in the order listed. Add a website link to make the logo clickable.

End of season

At the end of each season: 1. set Status to Final on the Season settings tab, 2. save the season to History, 3. start the next season. Saved seasons appear on the leaderboard's History tab, where anyone can open the full leaderboard exactly as it finished.

Starting the next season keeps your events, venues, clubs, logos and sponsors. It clears the dates, statuses, results links and fixes, and sets the new season to Live.

Past winners

For seasons before this website. Seasons saved to History fill themselves in, so there's no need to add them here. Use the club's name exactly as on the Clubs tab so its logo shows.

Update status

The leaderboard updates every 3 hours and after every change you save. Each update takes about 2 minutes. If an update fails, open it to see why, or ask for help.

Data check

Players who weren't counted and any problems with your links or fixes are listed on the leaderboard's Data check page.
